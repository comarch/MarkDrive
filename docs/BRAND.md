# Brand and listing kit

This kit contains proposed Comarch MarkQuire product branding and ready-to-use listing copy.

Before external publication, confirm the Comarch name, wordmark treatment, colors, and support contact with the internal brand owner. The repository includes a proposed text lockup, not the corporate master logo artwork.

## Product name

- First mention: **Comarch MarkQuire**
- Short name: **MarkQuire**
- Descriptor: **Markdown authoring and review for Google Drive**
- Do not write: `Mark Quire`, `Markquire`, or `ComarchMarkdown`

Recommended headline:

> Markdown for writers. Google Drive for reviewers.

Recommended one-sentence pitch:

> Comarch MarkQuire gives Google Workspace teams a Drive-native place to write and review portable Markdown files with rich technical previews.

### Clear space and sizing

- Keep clear space around the horizontal lockup equal to half the icon height.
- Do not place the light lockup on a busy or low-contrast image.
- Use the icon without text below 120 px of available width.
- Keep the favicon simple. Do not add a tagline or extra symbol.
- Do not stretch, rotate, recolor, or add effects to the mark.

## Google Workspace listing copy

### App name

```text
Comarch MarkQuire
```

### Short description

```text
Write and review portable Markdown without leaving Google Drive.
```

### Long description

```text
Comarch MarkQuire brings Markdown authoring and review into your existing Google Drive workflow.

Open .md files from Drive or create a new document in the current folder. Write with a fast source editor while a polished preview renders tables, task lists, highlighted code, KaTeX formulas, and Mermaid diagrams.

Reviewers can discuss exact passages using anchored Google Drive comment threads. Authors can reply, resolve, reopen, and navigate feedback without converting the document to another format.

Files remain portable Markdown. Export the source, create styled HTML, or print to PDF when another audience needs a fixed document.

MarkQuire is designed for engineering, product, operations, support, and technical writing teams that use Google Workspace as their shared document environment.
```

Screenshot rules:

- use the production lockup;
- show realistic but non-sensitive sample content;
- remove user tokens, private Drive links, and real personal data;
- keep browser chrome out unless it adds useful context;
- capture at 1440 x 900 or a matching 16:10 ratio;
- use short benefit-led captions.

The interface follows Material 3 patterns (segmented pill controls, soft
elevated surfaces, page-like centered canvas) on the existing brand palette.
It borrows layout conventions only: no Google fonts, logos, or product
iconography ship in the bundle, so Marketplace trademark review sees a
distinct product. Recapture the screenshot set after interface changes.
