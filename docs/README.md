## Product in one sentence

Comarch MarkQuire gives Google Workspace teams a Drive-native place to write and review portable Markdown files with rich technical previews.

## Current release

The current pre-1.0 release includes the core editor, preview, Drive file
lifecycle, anchored comment threads, document outline, MD/HTML/PDF export, save
conflict detection, Drive version history, image paste and upload, search and
replace, and interactive task checkboxes. Google Cloud and Workspace setup
remain deployment-specific.
