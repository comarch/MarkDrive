# Code of Conduct

This project follows the [Contributor Covenant Code of
Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior privately through [GitHub private vulnerability reporting](https://github.com/comarch/MarkQuire/security/advisories/new).

Project maintainers are responsible for clarifying and enforcing this standard
in a fair and consistent way.
